# MOSAIC

**MOSAIC (Whose Windows Glow?)** — an original, source-attributed indie-electronic song and composable music-video project.

- [Suno take 1](https://suno.com/song/38f117cc-015a-4c44-98dd-cfae3f1acd89)
- [Suno take 2](https://suno.com/song/96eb7115-e587-416d-b175-0e428c17f634)
- [Source interview: Machine Learning Street Talk with Alex Imas](https://www.youtube.com/watch?v=cB1GNO95iog)

The film explores economic measurement, organizational intelligence, falling prices, demand, wages, political economy, and scientific provenance. Video development happens in reviewable feature branches; `main` is intentionally minimal at initialization.
